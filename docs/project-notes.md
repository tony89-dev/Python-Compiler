# Project Notes

This document provides a short overview of the Latte Compiler project and its development structure.

## Purpose

The goal of this project is to demonstrate the core structure of a compiler implementation.
It is useful for reviewing parsing logic, source file organization, and compiler workflow design.

## Development Notes

When working on this project, changes should be kept small and easy to review.
Compiler-related changes can affect multiple parts of the project, so each update should be tested carefully before it is merged.

## Suggested Review Flow

1. Review the source files related to the change.
2. Check whether the change affects parsing, validation, or output generation.
3. Run the available tests or sample commands.
4. Confirm that the repository structure remains clean.

## Repository Maintenance

Documentation should stay simple and practical.
Small notes like this help future contributors understand the project faster.
